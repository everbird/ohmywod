# 手机分页友好化计划

## 1. 目标与授权边界

首轮从 `v2.4` / `b9422b9` 建立 `feature/mobile-pagination`，实现并部署本地预览；PR #13 已合并，并随 `v2.5` / `cf2727d` 发布。本次按用户追加要求，从 v2.5 建立 `feature/pagination-boundary-links`，补充窄屏首页/尾页快捷按钮。

本轮只优化分页交互，不改变搜索范围、目录查找、排序、每页数量、收藏类型、数据库结构或配置类语义。不加入无限滚动、异步加载列表、前端框架或新运行依赖。首轮发布已获用户单独授权并完成；此次追加已实现分支和本地预览，用户现已授权提交、push 并开 PR；合并、打 tag、修改 ops 或发布生产仍需另行授权。

## 2. 已确认的交互

窄内容区使用一行控件：

```text
[ « ] [ ‹ ] [ 3 ] / 58 [ 跳转 ] [ › ] [ » ]
```

- 当前页本身就是可编辑输入框，不另占一份“第几页”显示。
- 两端 `«` / `»` 为首页/尾页，中间 `‹` / `›` 为上一页/下一页；都使用普通链接和明确无障碍标签。
- 控件保持 44px 高；极窄内容区只允许箭头宽度由 44px 收窄至 28px，输入保持 16px 字号和四位数字空间，让 320px 下的七项控件仍在同一行。
- 总页数持续可见；输入数字后点击“跳转”或提交表单才导航，不在输入中或失焦时自动跳转。
- 输入框使用数字键盘提示；聚焦时尝试全选当前页，方便替换。
- 校验整数、必填及 1～总页数范围；无效输入提示，不能提交到错误页。
- JavaScript 启用后，“跳转”只在有效且不同于当前页时可用；无 JavaScript 仍保留原生 GET 表单和 HTML 范围校验。
- 未提交的输入不影响左右链接，左右翻页以实际当前页为准。
- 首页同时禁用首页/上一页，尾页同时禁用下一页/尾页；零结果或只有一页时不显示多余分页控件。
- 首尾链接不受未提交或非法输入影响，并保留全部现有查询参数；手工越界 URL 仍保持原服务器行为，但可通过首页/尾页回到有效页面。
- 页码输入、箭头和跳转按钮必须保持同一行，不做弹窗、固定悬浮栏或滑动手势翻页。

## 3. 宽屏与 iPad 策略

保留现有 `flask-paginate` 生成的桌面数字分页，其链接规则和样式不改。

优先按分页容器的实际宽度切换，不按设备型号或触摸能力一刀切：

- 初始拟定以 **560px** 内容宽度为界；低于该值使用紧凑组件，达到该值保留数字分页。实施时用数字较多的中间页和窄屏实测。
- iPad 宽屏内容区够宽时使用原数字分页；侧栏展开、分屏后内容变窄则使用紧凑分页。
- 使用 CSS container query；不支持它的旧浏览器按现有 768px 视口断点降级，不引入设备识别或新布局脚本。
- 保持现有侧栏开关、列表/网格偏好以及宽屏分页的尺寸、间距与内容不变。
- 顶部只在紧凑模式提供同一行分页，底部提供完整的响应式分页，避免知道目标页时必须先滑完列表。宽屏顶部不出现新增控件或空白。

## 4. 实施范围与参数契约

当前共有四个分页页面：全部目录 `root.html`、目录战报 `category.html`、搜索结果 `search.html`、我的战报收藏 `favor.html`。

- 建立一个共享 Jinja 分页片段，使用现有 Pagination 的 page / total_pages，不增加数据库查询。
- 跳页表单提交到当前路由；分页链接和表单均保留 q、per_page 及其他已有查询参数，包括重复值，替换而不叠加旧 page。
- 不把查询参数作为 url_for 的路由/外链选项，避免参数改变提交路径。
- 输出保持 Jinja 转义，跳页为同窗口 GET，无 CSRF 写请求、fetch 请求或业务状态修改。
- 不改已有手工输入越界 URL 的服务端空结果行为；新增控件提供有效范围内的导航。本轮不借分页工作调整筛选逻辑。
- 使用小型静态 JavaScript 增强输入校验与选择；不能吞掉普通链接、浏览器返回或修改历史状态。
- 修改 custom.css 时更新其现有缓存版本，新脚本使用明确的缓存标识；不建立资产构建系统。

## 5. 验证与验收

### 自动回归

- 四个路由均使用共享组件；首/中/末页、零结果和单页行为正确。
- 当前页、总页数、上一页/下一页目标正确，未提交值不改变链接。
- GET 跳页保留筛选、每页数量、重复参数；特殊字符安全编码/转义，page 唯一。
- 宽屏片段与原 Pagination.links 相同，已有阅读器/搜索/收藏语义不变。
- 全量 pytest、依赖检查和 whitespace 检查。

### 浏览器

- 320、390、767、768、1024、1440px 视口及横屏；实际内容区在 560px 阈值两侧。
- 检查控件同一行、触摸面积、无页面溢出、输入焦点与数字键盘属性、键盘提交、非法输入和第一/末页禁用。
- 测试输入目标页后选择左右翻页、保留查询参数、同窗口导航与返回。
- 切换侧栏、列表/网格；模拟 iPad 宽屏和分屏尺寸，不宣称已在真实设备验收。
- 无 JavaScript 与旧 CSS 降级不导致重复控件；standalone CSS 路径单独记录，不等同安装验收。

### 本地部署

先检查既有本地 web、数据库、Redis 和 HTTPS 代理的实际状态。保留已有数据、ignored 开发配置和现有 Redis，不运行 gen.py/init_db 或覆盖已有数据库。

若先前 `/tmp` 服务运行目录或临时数据库已消失，使用独立、明确标记的演示数据和本地预览配置恢复验收环境，不假装原服务仍在运行，不初始化或混入用户数据。不改 DNS、不操作生产。最终提供实际可用的 HTTP/HTTPS 地址及可演示多页的链接。
