# 更新日志

这里记录每次正式版本中用户可见的新增、改进和修复。战报仍需联网查看。

## [Unreleased]

### 改进
- 窄屏分页改为单行上一页、页码输入／总页数、跳转和下一页；目录、战报、搜索结果和收藏列表顶部也能直接跳页。
- 分页按实际内容宽度适配，空间够宽时保留原数字分页；跳页保留查询参数，并提供输入校验和无 JavaScript 回退。

## [v2.4] - 2026-10-04

### 新增
- 主内容区域底部显示当前代码的版本、Git commit 以及更新日志入口；侧栏不增加版本信息，手机独立窗口也保留主内容区的版本行。
- 新增匿名可访问的更新日志页面，按版本查看具体变化。

### 改进
- 版本信息与更新记录在 web 启动时读取并缓存；未打标签或本地修改的代码明确标记为预览，不冒充正式发布。
- 窄屏信息卡中的长联系方式可自动换行，不再撑大页面。

[查看源码](https://github.com/everbird/ohmywod/tree/v2.4) · [与 v2.3 比较](https://github.com/everbird/ohmywod/compare/v2.3...v2.4)

## [v2.3] - 2026-10-04

### 修复
- 桌面端隐藏手机快捷导航标题和搜索图标，包括继续使用旧自定义样式的浏览器；手机端保留原有顶栏。
- 更新自定义 CSS 的缓存标识，避免发布后继续加载旧样式。

[查看源码](https://github.com/everbird/ohmywod/tree/v2.3) · [与 v2.2 比较](https://github.com/everbird/ohmywod/compare/v2.2...v2.3)

## [v2.2] - 2026-10-04

### 新增
- 增加手机桌面安装所需的 manifest、安装图标与帮助说明，继续使用联网网页，不提供离线缓存。
- 手机端提供战报网、搜索快捷入口和遮罩式侧栏，独立窗口内可完成站内导航。

### 改进
- 战报宽表在阅读内容区横向滚动，不再撑大整个页面；调整返回栏高度与内容起点，手机横屏也保留返回入口。
- 阅读器的返回链接保持原生导航，支持键盘操作；站内使用示例在当前窗口打开。
- 恢复完整的网站帮助内容，安装说明只作为一个简短章节；空目录页面增加使用帮助入口。
- 侧栏 Logo 与 WoD 图片按剩余高度自适应，保留底部账号入口；手机独立窗口隐藏网页式页脚。

### 修复
- 没有跳转目的地的信息型浮窗不再显示「前往」，并清除前一个浮窗的跳转处理器。

> 安装后的系统界面与行为取决于手机和浏览器；本版的布局及导航已做自动检查，不代表所有目标设备的真实安装均已验收。

[查看源码](https://github.com/everbird/ohmywod/tree/v2.2) · [与 v2.1 比较](https://github.com/everbird/ohmywod/compare/v2.1...v2.2)

## [v2.1] - 2026-10-04

### 新增
- 提供邮件找回密码入口；忘记密码时可通过账号邮箱设置新密码。
- 提供爱发电支持入口和赞助者致谢页，支持微信、支付宝的手工致谢记录。

### 改进
- 账号认证改为 SQLite 存储，迁移已有账号，保留原用户名和密码登录方式。
- 反馈改为登录后提交，并通过邮件通知站长；保留站内论坛和邮件反馈入口。
- 战报上传全部成功后自动刷新目录页面。
- 减少阻塞式第三方资源，优化 Logo、阅读器静态资源及按页面加载的脚本/样式；原始战报使用边缘缓存。
- 为登录、注册、收藏和点赞等写入操作增加请求频率限制，并改进 ZIP/路径检查与异常提示。

### 移除
- 撤除 AdSense 广告及引导广告点击的文案，改为自愿支持。
